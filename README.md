# 瞄准工坊 - Valorant / osu! 灵敏度训练与测评工具

> 一款纯前端单页网页工具，帮助你科学定位最适合自己的游戏灵敏度，提供针对性的瞄准训练与角色定位测评。

---

## 📖 项目简介
很多玩家在调整灵敏度时仅凭感觉反复试错，难以找到稳定且适合自己的数值；同时缺乏针对性的基础功训练场景，也不清楚自己的打法风格适配什么位置。本工具将灵敏度换算、梯度对比测试、急停训练、osu! 瞄准测试、位置测评整合为一体，所有数据本地存储，无需安装，打开即用。

## ✨ 核心功能

### 1. 灵敏度测试与换算
- **多指标实时换算**：输入鼠标 DPI 与游戏内灵敏度，自动计算 eDPI、厘米/360°、英寸/360° 等核心指标
- **五档梯度盲测**：内置 0.7× / 0.85× / 1.0× / 1.15× / 1.3× 五档灵敏度虚拟靶场，每轮20个目标，通过命中表现对比手感差异
- **职业数据对照**：参考职业选手主流 eDPI 区间，给出适配你的推荐 eDPI 范围
- **多DPI档位方案**：自动生成 400 / 800 / 1600 DPI 三档对应的游戏内灵敏度换算结果

### 2. FPS 急停训练
- 模拟 Valorant 横向移动急停射击场景，A/D 键控制移动，反向键急停后点击射击
- 量化统计：命中率、急停响应时间、枪口偏移量、平均停稳耗时
- 支持多轮连续训练，生成平均成绩，辅助纠正急停节奏与开枪时机

### 3. osu! 瞄准测试
- 复刻 osu! 经典点击判定逻辑，分为 300（Perfect）、100（Good）、50（Bad）三档判定
- 四档灵敏度梯度测试，适配不同鼠标 DPI 与操作习惯
- 输出总准确率、各判定占比、平均偏移距离，辅助定位最佳手感

### 4. 位置适配测评
- 12 道倾向性测试题，从打法风格、反应习惯、团队角色、决策偏好四个维度评估
- 输出 Valorant 四大定位（决斗位 / 先锋位 / 控场位 / 哨兵位）的适配度评分
- 附带对应定位的推荐特工名单与特点说明

### 5. 个人综合报告
- 汇总所有模块测试结果，生成完整的个人灵敏度方案与训练建议
- 提供周训练计划与灵敏度微调步骤
- 浏览器本地保存历史测试记录，支持追踪长期进步

## 🎮 使用方式

### 在线使用
部署完成后直接通过浏览器访问即可，无需下载任何文件。
- 推荐环境：Chrome / Edge 浏览器，键盘 + 鼠标操作体验最佳
- 移动端：支持触屏操作，适合灵敏度体验对比

### 本地运行
1. 下载仓库中的 `index.html` 文件
2. 双击用浏览器打开即可使用
3. 所有数据保存在浏览器本地存储中，不会上传到任何服务器

## 🛠️ 部署到 GitHub Pages
1. Fork 或上传本项目到你的 GitHub 仓库
2. 进入仓库页面，点击顶部 **Settings**
3. 左侧菜单栏找到 **Pages**（位于 Code and automation 分类下）
4. 在 Build and deployment 区域：
   - Source 选择 `Deploy from a branch`
   - Branch 选择 `main` 分支，路径选择 `/ (root)`
   - 点击 **Save**
5. 等待 1-3 分钟，页面顶部会显示在线访问链接：
   `https://[你的用户名].github.io/[你的仓库名]/`

## 🧱 技术栈
- **前端**：原生 HTML5 + CSS3 + Vanilla JavaScript
- **无依赖**：不引入任何第三方框架、库或 CDN 资源
- **单文件**：所有代码整合在单个 HTML 文件中，离线可运行
- **数据存储**：浏览器 localStorage 本地存储，无服务端交互

## 📊 数据参考依据
- Valorant 职业选手 eDPI 参考区间基于公开赛事选手配置统计，主流区间 200-320 eDPI，中位数约 240 eDPI
- osu! 灵敏度标准参照官方鼠标灵敏度换算体系与通用游玩习惯
- 虚拟靶场测试为相对手感对比工具，最终灵敏度建议结合实战场景微调

## 💡 使用建议
1. 测试前保持鼠标 DPI 固定，关闭鼠标加速、指针精确度等系统设置
2. 灵敏度测试建议完成全部五档，再结合 1-2 天实战验证最终数值
3. 急停训练建议每天 5-10 分钟，重点关注停稳时机而非单纯速度
4. 位置测评仅作参考，实际定位可根据队伍配置与个人喜好调整

## ❓ 常见问题
**Q：测试数据会丢失吗？**
A：数据保存在当前浏览器本地，清除浏览器数据或更换浏览器会丢失，建议记录关键结果。

**Q：可以用来测试其他 FPS 游戏吗？**
A：灵敏度换算与急停训练适用于绝大多数 FPS 游戏，位置测评仅针对 Valorant 设计。

**Q：为什么测试出来的灵敏度和我平时用的差很多？**
A：工具给出的是统计参考区间，个人手感差异很大，建议以推荐值为基准上下微调。

**Q：移动端可以用急停训练吗？**
A：急停训练需要键盘操作，仅推荐电脑端使用；灵敏度与osu测试支持触屏。
