# 瞄准工坊 AimLab

为 **无畏契约（Valorant）** 与 **osu!** 玩家设计的一站式灵敏度测试与训练工具。通过多档灵敏度对照试验、急停专项训练、定位测试，帮你找到适合自己的 eDPI 与游戏内灵敏度，并输出可执行的调参建议与训练计划。

- 单文件 HTML，无需安装、无需联网依赖，浏览器打开即用
- 数据仅保存在本地浏览器（localStorage），不上传任何服务器

## 功能

| 模块 | 说明 |
| --- | --- |
| 灵敏度测试 | 5 档灵敏度（0.7×/0.85×/1.0×/1.15×/1.3×）各 20 目标，对照职业选手 eDPI 分布，输出推荐 eDPI 及 400/800/1600 DPI 换算 |
| osu! 瞄准测试 | 4 档倍率（0.8×/1.0×/1.2×/1.4×）各 18 个圆圈，300/100/50 判定，输出推荐 osu 灵敏度倍率 |
| 急停训练 | 3 轮 × 20 目标，A/D 移动 + 反向键急停 + 射击，量化停稳时间、停稳精度与命中率并评级 |
| 位置测试 | 12 题定位你的主角色（决斗 / 先锋 / 控场 / 哨兵），附推荐特工 |
| 报告 | 汇总各模块结果、行动清单、周训练计划与历史记录 |
| 隐藏鼠标 | 测试画布内隐藏鼠标光标，准星完全代替指针，模拟游戏环境（可开关） |

## 快速开始

1. 下载 ，用 Chrome / Edge 双击打开（不要用文件管理器的预览窗格）
2. 在「灵敏度」页输入你当前的 DPI 与游戏内灵敏度，跑完 5 档试验
3. 依次完成「急停」「osu」「位置」测试
4. 到「报告」页查看推荐配置与训练计划

### 测试前建议

- 关闭系统鼠标加速（Windows「鼠标属性 → 指针选项 → 提高指针精确度」取消勾选）
- 游戏中开启原始输入 / Raw Input
- 建议使用 800 或 1600 DPI

## 数据口径与参考来源

- eDPI = DPI × 游戏内灵敏度；厘米/360° = 360 / (0.07 × eDPI) × 2.54（无畏契约 yaw = 0.07）
- 职业选手 eDPI 分布参考：
  - proconfig.net/stats/valorant-edpi-distribution（中位数约 240）
  - esportsmice.com/games/valorant（平均约 251）
  - setup.gg/game/valorant/best-sens（668 人平均 248.3 / 中位数 231.2）
  - ultimatemove.eu/en/valorant-edpi-calculator（主流区间 250–320，约 45 cm/360°）
- osu! 灵敏度参考：osu 官方 wiki（Raw Input）、Liquipedia osu 选手鼠标设置（如 ASecretBox 800 DPI × 0.9）

> 测试结果仅供个人参考，最终以实战手感为准。
